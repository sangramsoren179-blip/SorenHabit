# SorenHabit

A simple and modern habit tracker built from scratch using HTML, CSS, and JavaScript.

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
SorenHabit/
├── css/
│   ├── base.css
│   ├── habits.css
│   ├── header.css
│   ├── main.css
│   ├── overview.css
│   ├── reset.css
│   └── variables.css
├── js/
│   ├── app.js
│   ├── date.js
│   ├── dom.js
│   └── habits.js
├── .gitignore
├── index.html
└── README.md
```
