# SorenHabit

A simple and modern habit tracker built from scratch using HTML, CSS, and JavaScript.

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
SorenHabit/

│   ├── habits.css
│   ├── header.css
│   ├── main.css
│   ├── overview.css
│   ├── reset.css
│   └── variables.css
├── js/
│   ├── app.js
│   └── dom.js
├── .gitignore
├── index.html
└── README.md
```
